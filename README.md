# Enterprise Sales Performance & Predictive Analytics System

## 📌 Project Overview
Architected an enterprise revenue forecasting system integrating 3 years of historical sales records across 15 global product lines using Advanced SQL and Python.

## 🔑 Key Deliverables & Achievements
- **Data Governance & Validation**: Engineered automated Python and SQL data cleansing scripts, achieving **99.5% data consistency** across multi-region transaction tables.
- **Predictive Forecasting**: Developed a time-series forecasting pipeline predicting 180-day revenue trends with **92% historical accuracy**.
- **Interactive Tableau Storyboard**: Identified **$1.5M+ in cost-saving and cross-selling opportunities** across underperforming SKUs.

## 🛠 Tech Stack
- **Data Processing & SQL**: Advanced SQL, Stored Procedures, Multi-table Joins
- **Predictive Modeling**: Python, Pandas, Scikit-learn, Prophet
- **Business Intelligence**: Tableau Desktop, Advanced Excel
